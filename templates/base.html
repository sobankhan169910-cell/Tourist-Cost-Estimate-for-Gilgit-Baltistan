About Tour Cost Estimator

A lightweight, precision analytical engine built with Python, Flask, and NumPy. Provides instant itemized breakdowns, group discounts, historical percentiles, and linear price forecasts.

Calculation Rules

  • Low Season: 0.8× (20% Off)
  • Shoulder Season: 1.0× (Standard)
  • Peak Season: 1.3× (+30% Surcharge)
  • Group Discount: 10% Off for 5+ Travelers

NumPy Data Science

  • Vectorized 2D Matrix Computations
  • 25th, 50th, 75th Percentiles for History
  • 1st-Degree Polyfit Linear Forecasting
  • REST JSON API: /api/estimate
